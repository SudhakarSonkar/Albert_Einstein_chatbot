# 🧠 Chat with Albert Einstein

This project is an AI-powered chatbot that simulates conversations with **Albert Einstein** using **Google Gemini** (via LangChain) and a **Gradio web interface**.  
Einstein responds in a witty, humble, and insightful way — just as you would expect from the great physicist himself.

---

## 🚀 Features
- Talk to "Albert Einstein" in a warm, conversational tone.
- Explains physics, philosophy, creativity, and life using analogies.
- Provides witty insights and sometimes famous quotes like  
  _"Imagination is more important than knowledge."_
- Works in both **Terminal** and **Web UI (Gradio)**.
- Interactive chat history with the ability to **clear conversations**.
